# 软件架构说明

## 三层结构

| 层 | 模块 | 说明 |
| --- | --- | --- |
| 入口 | `main.py` | download / events / sync-events / discuss / doctor |
| 业务 | `shishipinglun/downloader.py`、`shishipinglun/events/*` | 下载、事件同步、评论数据库 |
| 界面 | `shishipinglun/events/static/` | 网页前端（事件列表、评论、讨论、工具入口） |

## 数据流

```text
新闻源(RSS/HTML) ──sync_events.py──▶ database.json ──server.py──▶ 网页
                                                      ▲
用户评论 ──POST /api/comments──▶ database.json        │
用户点“想讨论” ──▶ 告诉 Codex ──▶ record_discussion.py ─┘
```

## 关键技术点

- Python 标准库 `http.server` 提供本地网页服务，无框架依赖；
- JSON 文件单机存储，带写入锁与原子替换；
- PDF 使用 PyMuPDF 内置中文字体 `china-s`，Word 使用 python-docx；
- 各来源解析器独立成函数，站点改版时只需改对应 selector。
