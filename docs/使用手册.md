# 时评与事件中心 · 使用手册

## 一、这是什么

一个本地运行的桌面软件，功能分三块：

1. **文章下载**：把人民日报（人民时评/今日谈）、求是、半月谈、纽约时报观点下载成 PDF/Word，按三大类别放进桌面 `时评文章下载` 文件夹；
2. **事件中心**：自动收录国内外要闻，也可以手动记录一件具体的事；
3. **评论与讨论**：在事件下写评论，和 Codex 讨论后，回复会写回软件里长期保存。

## 二、安装

### 方式 A：安装版（推荐）

打开 `时评与事件中心.app`（已安装到“应用程序”，或双击 DMG 里的应用拖入）。

首次打开如果提示“无法验证开发者”，请：右键应用 → 打开 → 再点“打开”。

### 方式 B：源码运行

```bash
cd ~/Documents/GitHub/shishipinglun-hub
python3 -m pip install -r requirements.txt
python3 main.py desktop
```

## 三、界面与操作

### “事件中心”页

- 顶部可搜索标题/来源，点“🇨🇳 国内 / 🌐 国际”筛选；
- “🔄 同步最新事件”按钮抓取最新要闻；
- “＋ 手动添加事件”记录自己关心的具体事件；
- 点事件卡片进入详情，可打开原文、写评论。

### 写评论与讨论

1. 在事件详情下方输入看法，点“发表评论”；
2. 评论下方点“想和 Codex 讨论”，该条会标记为“待讨论”；
3. 回到 Codex 对话框，说“讨论事件 X 里我写的评论”；
4. Codex 给出看法后写入软件；回到“我的评论”页即可看到完整讨论记录。

### “文章下载器”页

- 填“每栏目篇数”，点“▶ 现在下载”，PDF+Word 会自动保存到桌面；
- 下面也提供了命令行版用法与复制按钮。

## 四、数据存放在哪里

- 事件/评论/讨论：`~/Library/Application Support/ShishipinglunCenter/database.json`
- 文章文件：`~/Desktop/时评文章下载/`

删除 `database.json` 会清空事件中心数据；删除桌面文件夹不影响软件。

## 五、定时任务

Codex 中已注册“每日时评文章自动下载与事件同步”（每天 08:30）：

- 各栏目最新 5 篇（PDF+Word）写入桌面；
- 国内外最新事件同步进事件中心；
- 运行结果会在 Codex 对话框里汇报。

## 六、常见问题

**NYT 为什么只有摘要？**

NYT 文章页有订阅与反爬限制；工具会保存官方 RSS 摘要与原文链接，并标注提示。

**网站改版后抓不到文章？**

人民网/求是/半月谈改版时，需要同步更新对应解析器（见 `shishipinglun/downloader.py` 与 `sync_events.py`）。

**想清空事件重新开始？**

退出软件后删除 `~/Library/Application Support/ShishipinglunCenter/database.json` 再启动。

## 七、隐私与合规

- 全部数据保存在本机，不上传；
- 抓取频率默认较低，仅供个人学习、离线阅读；
- 请勿对抓取内容做商业转载；NYT 内容请遵守其订阅条款。
