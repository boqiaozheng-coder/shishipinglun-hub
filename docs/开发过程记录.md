# 开发过程记录（整理版）

> 本文按时间顺序整理整个项目的来源、演进与关键技术决策，方便日后复盘与维护。

## 2026-09-02 需求诞生

用户希望有一个工具：

1. 把“人民时评 + 今日谈”下载为 PDF/Word 到桌面；
2. 求是网与半月谈文章，同样下载；
3. NYT Opinion 栏目同格式；
4. 在桌面按三大类别建立文件夹；
5. 后续扩展：国内外事件记录 → 用户评论 → 与 Codex 讨论；
6. 前端界面 → 独立桌面窗口软件 → 打包“上架”。

## 阶段一：文章下载 CLI（v0.1）

**调研**：逐一探测人民网“人民日报重要言论库”、求是“社论评论”、半月谈“评论”栏目页；

**实现**：`download_articles.py` 单文件工具：

- 人民网：言论库栏目列表 → 详情页正文；
- 求是：`#detailContent` 正文容器；
- 半月谈：`div.detail_content` 正文容器；
- 导出：python-docx（Word）+ PyMuPDF 内置中文字体 `china-s`（PDF）；
- 归档：`01_人民日报_人民时评与今日谈 / 02_求是网与半月谈 / 03_纽约时报观点`。

**遇到的问题与解决**

| 问题 | 解决 |
| --- | --- |
| 人民网列表正则在 `/n1/2026/0902/` 与 `/n1/20260831/` 之间误判 | 改为两段式 `20xx/xxxx` 匹配 |
| 正文混入“分享让更多人看到”等杂质 | 增加正文清洗规则 |
| PDF 中文字体缺失 | 使用 MuPDF 内置 `china-s` |
| PyMuPDF `lineheight` 参数语义误解 | 确认是字号倍数并修正 |
| 半月谈作者行与页面 meta 冲突 | 以正文署名行优先 |

## 阶段二：NYT 接入

- NYT 使用官方 RSS（Opinion / World）；
- 完整正文页遇到 DataDome 反爬（403），尝试 requests 完整浏览器头、无头 Chrome 均被拦截；
- 决策：**正文失败自动回退为 RSS 摘要 + 原文链接**，不绕过订阅限制；
- 当前网络不可达时友好提示，不阻塞其他来源。

## 阶段三：定时自动运行

在 Codex 注册 heartbeat 定时任务：

- 每天 08:30 下载文章 + 同步事件；
- 汇报成功/失败，NYT 连不上视为预期情况。

## 阶段四：事件中心

新增本地事件中心：

- 数据：JSON 文件（后来外置到 Application Support）；
- 事件源：人民网时政（国内）、人民网国际 + NYT World（国际）；
- 评论与“想讨论”标记；
- `record_discussion.py` 把 Codex 回复写回评论，形成闭环。

## 阶段五：整理为代码库

- 迁移到 `~/Documents/GitHub/shishipinglun-hub` 并 git 管理；
- 包结构 `shishipinglun/`，统一入口 `main.py`；
- 前端增加“文章下载器”入口；
- 路径改为代码库正式路径，定时任务同步更新。

## 阶段六：桌面窗口

- 选择 **pywebview**（原生窗口 + 本地 HTTP 服务），避免 Electron 的大体积与依赖；
- 端口占用自动顺延；
- 关闭窗口即停止服务。

## 阶段七：一键下载进窗口

- 服务端增加 `/api/download` 与 `/api/download-status`；
- 下载改为进程内执行（为打包版做准备），避免依赖子进程模块路径；
- 前端轮询状态、完成时显示“共生成 N 个文件”。

## 阶段八：打包 .app 与用户数据外置

- 使用 **PyInstaller**（onedir windowed bundle，约 88 MB）；
- 数据目录改为 `~/Library/Application Support/ShishipinglunCenter/`；
- 首次运行自动迁移仓库初始数据；
- 静态资源定位兼容开发/打包（`sys._MEIPASS`）；
- 生成图标（“评”字蓝底）与 DMG 安装镜像。

## 验证记录（重要）

- 中文四栏目端到端抓取 + PDF/Word 内容完整性核对通过；
- `--days` 时间过滤冒烟通过；
- NYT 离线 RSS 回退通过；
- 事件中心增删查、评论、讨论回写闭环通过；
- 桌面窗口内一键下载（.app 打包版）实测通过，10 个文件生成；
